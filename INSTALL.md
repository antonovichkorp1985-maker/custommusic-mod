# Установка мода CustomMusic

## Для игрока

1. Установи **Minecraft 1.19.2** и **Forge 43.4.0+**.
2. Скачай **`custommusic-1.0.0-all.jar`** (именно `-all`, fat jar).
3. Закинь его в папку `mods/`.
4. Запусти игру один раз и закрой.
5. В корне игры появится папка `custommusic/`.
6. Скопируй туда музыку:
   ```
   custommusic/
     Artist/
       Album/
         01 - Track.mp3
     Another Artist - Track.flac
   ```
7. Запусти игру, нажми **M** (англ.) — откроется плеер. Если треки не появились сразу, нажми **Обновить**.

## Для разработчика (сборка из исходников)

Требования: JDK 17, Git, интернет.

```bash
git clone https://github.com/ТВОЙ_НИК/custommusic-mod.git
cd custommusic-mod
./gradlew shadowJar       # Linux/Mac
.\gradlew shadowJar       # Windows PowerShell
```

Готовый файл: `build/libs/custommusic-1.0.0-all.jar`.

## Горячие клавиши

- **M** — открыть плеер
- **P** — пауза / играть
- **N** — следующий трек
- **B** — предыдущий трек
- **← / →** — предыдущий / следующий
- **Пробел** — пауза

## Если что-то не работает

- Смотри `logs/latest.log`, ищи `[CustomMusic]`.
- Если пишет "Неподдерживаемый аудио формат" — скорее всего, используется не fat jar.
- Если экран открывается пустым — подожди, идёт фоновое сканирование большой библиотеки.
